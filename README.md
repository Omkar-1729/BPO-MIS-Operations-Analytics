# BPO MIS Operations Analytics

A Business Process Outsourcing (BPO) MIS analytics project built using **MySQL, SQL, and Microsoft Power BI** to analyze operational performance, workload, service quality, and agent performance.

## Project Overview

This project demonstrates how operational data can be transformed into meaningful MIS insights using SQL-based analysis and an interactive Power BI dashboard.

The analysis focuses on key BPO operational metrics such as:

- Ticket volume
- Tickets received and resolved
- Resolution percentage
- Backlog
- Average AHT (Average Handle Time)
- SLA performance
- CSAT (Customer Satisfaction)
- Escalations
- Category workload
- Agent performance

## Tools & Technologies

- **MySQL** – Data analysis and SQL queries
- **SQL** – KPI calculations, aggregations, and operational analysis
- **Power BI** – Interactive dashboard and data visualization
- **Microsoft Excel / CSV** – Source data and data preparation
